# IPC Handlers

Create small domain files such as:
- auth.ipc.cjs
- customers.ipc.cjs
- vehicles.ipc.cjs
- appointments.ipc.cjs
- mechanics.ipc.cjs
- jobs.ipc.cjs
- inventory.ipc.cjs
- invoices.ipc.cjs
- payments.ipc.cjs
- expenses.ipc.cjs
- reports.ipc.cjs
- backup.ipc.cjs

Handlers validate input, enforce role permissions, then call service functions.
